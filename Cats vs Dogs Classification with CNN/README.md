# Cats vs Dogs Classification with CNN

<p>Build a classifier for distinguishing between cats and dogs in images using a convolutional neural network implemented with TensorFlow.</p>

## Technologies Used
<p style='font-weight: bold'>
NumPy | Python | seaborn | Tensorflow | Matplotlib
</p>

## Project Description
This project aims to build a binary classifier to distinguish between the images of cats and dogs. For this purpose, I build a convolutional neural network (CNN) using TensorFlow, a popular open-source software library for machine learning. CNNs are a type of deep learning algorithms that are particularly effective for image classification tasks. They consist several layers that perform convolutions and pooling operations on the input images to extract important features.

I use a dataset of images containing cats and dogs. This dataset is split into training, validation, and testing sets for training and evaluation purposes.
