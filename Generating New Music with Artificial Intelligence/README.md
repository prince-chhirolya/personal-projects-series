# Generating New Music with Artificial Intelligence

<p>In this project, I use the open-source framework AudioCraft from Meta AI to generate original music compositions in different genres. We’ll also customize the output by providing input instructions and fine-tuning the model.</p>

## Technologies Used
<p style='font-weight: bold'>
AudioCraft | Meta AI | Python | PyTorch
</p>

## Key Learnings

* Utilize the concepts of AI-based music generation.
* Develop a user interface for the music generation system.
* Generate music in different genres.
* Compare audio outputs generated with different prompts.
