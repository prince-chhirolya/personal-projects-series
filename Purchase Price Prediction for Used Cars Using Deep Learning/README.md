# Purchase Price Prediction for Used Cars Using Deep Learning

## Technologies Used
<p style='font-weight: bold'>
Python | Pandas | seaborn | Tensorflow
</p>

## Project Description

In this project, I build a neural network that predicts used car sale prices based on vehicle attributes and buyer characteristics. Using TensorFlow and Keras, I create a regression model that learns from historical sales data to estimate prices for new listings. This machine learning for price prediction project covers data preprocessing, exploratory visualization, and model training with performance evaluation using Python.

I start by loading the dataset, handling missing values, and performing categorical to numerical conversion for seamless neural network processing. Using seaborn data visualization, I create pairplots and comparative charts to explore correlations between car features, buyer demographics, and sale prices through correlation analysis. Next, I build a Sequential model architecture with Dense layers and a linear output for continuous value prediction, compile it with mean squared error optimization, and train while monitoring for overfitting detection. Finally, I evaluate the model on testing data using mean absolute error and R-squared score metrics to measure prediction accuracy.
