# Diabetes Prediction Using Keras

<p>In this project, I predict diabetes with a neural network model using the Python Keras library. We'll use libraries like seaborn and matplotlib to create visualizations, and then evaluate the model.</p>

## Technologies Used
<p style='font-weight: bold'>
Keras | Python | seaborn | TensorFlow | Data Science | Data Visualisation | Deep Learning
</p>

## Key Learnings
* Perform various preprocessing steps such as handling missing values and data skewness, scaling, etc. 
* Perform exploratory data analysis and create meaningful visualizations.
* Build simple neural networks with Keras and TensorFlow.
* Train and evaluate models using various metrics and visualizations. 

## Project Description

In this project, I use the Python Keras library to create neural networks and use them to predict diabetes with patient health data.

I load and analyze the data using pandas, visualize it using matplotlib and seaborn. I perform data cleaning, preprocessing and feature selection, and then split it into training, validation and testing datasets using NumPy. After the data is ready, I train simple deep learning models using Keras. I then plot the training curves and perform model evaluation using scikit-learn.
