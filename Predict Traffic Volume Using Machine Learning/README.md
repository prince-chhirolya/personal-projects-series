## Project Description

Predicting traffic flow using real-time data has numerous real-world applications, including optimizing traffic light timings, reducing traffic congestion, and improving fuel efficiency. This project involves developing a machine learning-based system to predict traffic volume on the I-5 North Freeway in Seattle, WA. 

I load and preprocess the dataset using pandas and NumPy, analyze the data using matplotlib and seaborn, and split it into training and testing sets. Next, I train and compare multiple machine learning models, including Linear Regression, Decision Tree, Random Forest, XGBoost, and Neural Networks. Finally, I evaluate the models using metrics like MAE, MSE, RMSE, and R² score to identify the best-performing algorithm for predicting traffic volume.
